2. إذا فشل Docker build:
   - تحقق من توفر المساحة: $ docker system df
   - نظف المساحة: $ docker system prune -a
   - أعد المحاولة: $ docker compose build app --no-cache

3. إذا كان التطبيق بطيئاً:
   - تحقق من الموارد: $ docker stats
   - زد حد CPU/Memory في docker-compose.yml
   - تحقق من قاعدة البيانات: $ docker exec -T db mysql -e "SHOW PROCESSLIST"

4. للمراقبة المستمرة:
   - استخدم: $ watch -n 5 'docker compose ps'
   - استخدم: $ docker logs ins2026-app -f
