# Third-Party Notices

Last updated: 2026-03-28

This file tracks third-party assets, libraries, fonts, icons, and media used in the project, with license and attribution details.

## How to Maintain

For each third-party asset/package, record:
- Name
- Source URL
- Version
- License
- Attribution requirements
- Commercial-use status

## Media/Brand Assets

Record all non-original assets used under:
- `public/images/`
- `public/Videos/`
- `resources/images/`

For each item, store creator/source/license proof in internal compliance records.
